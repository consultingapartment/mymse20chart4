# chart4report

МХБ-ийн 20 компанийн **албан ёсны хаалтын ханшаар** (open.mse.mn) 4 чарт гаргаж Telegram руу илгээнэ.
Хэлцлийн (deals) өгөгдөл, marketinfo API огт ашиглахгүй.

| Чарт | Команд |
|---|---|
| Сарын ханшийн хөдөлгөөн | `python chart4.py monthly` |
| Улирлын ханшийн хөдөлгөөн | `python chart4.py quarterly` |
| Хагас жилийн ханшийн хөдөлгөөн | `python chart4.py halfyearly` |
| Жилийн ханшийн хөдөлгөөн | `python chart4.py yearly` |
| 4-үүлээ | `python chart4.py all` |
| Автомат (шинэ сар эхлэхэд сүүлд дууссан үеийг) | `python chart4.py auto` |

## Файлууд
- `history_mse.py` — open.mse.mn-ээс хаалтын ханш татна (`discover`, `backfill`, `update`, `probe-list`, `probe`)
- `history_excel.py` — бүх цаг үеийн түүхийг нэг Excel болгоно: `reports/mse_history.xlsx`
- `index_mse.py` — МХБ-ийн ТОП-20 индекс (members.mse.mn-ээс өдөр бүр хуримтлуулна)
- `alert.py` — алдааны мэдэгдэл ба Excel-ийг хувийн Telegram чат руу
- `tests/smoke.py` — автомат тест
- `chart4.py` — 4 чартын тооцоо
- `render_chart.py`, `render_base.py` — PNG зурна (Pillow)
- `send_telegram.py` — Telegram руу зураг + тайлбар илгээнэ (давхар илгээхгүй)
- `.github/workflows/charts.yml` — GitHub Actions

## Тохиргоо
1. Репод secrets нэмнэ: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (суваг), `TELEGRAM_ADMIN_CHAT_ID` (таны хувийн чат —
   ботод нэг удаа /start бичсэн байх ёстой).
2. Actions → **Run workflow** → `chart = all`. Анх удаа `data/history/security_ids.json` байхгүй тул
   бүх цаг үеийн түүхийг автоматаар татаж `reports/mse_history.xlsx` үүсгээд 4 чартыг илгээнэ.
3. Цаашид Даваа–Баасан 13:30-д ханш шинэчилж, шинэ сар эхэлсэн өдөр сүүлд дууссан сарын
   (улирал / хагас жил / жил дууссан бол тэдгээрийн ч) чартыг нэг удаа илгээнэ.

Хуучин mse-collector репоны `data/history/` хавтсыг хуулж оруулбал дахин татах шаардлагагүй.

## Тооцооллын дүрэм
- Компани бүр **өөрийн түүх эхэлсэн өдрөөс** тооцогдоно (нэрийн баруун талд "2012.01-" гэх мэт).
  Түүх эхлэхээс өмнөх үе "—".
- **Нийтлэг эхлэл: 2023-05-01** (`COMMON_START`). Хагас жил, жилийн "Нийт" багана бүх 20 компанид
  2023-05-01-ний өмнөх сүүлийн хаалтаас тооцогдоно. 2023-05-01-нээс өмнөх түүх нь багана тус бүрт (2023.H1, 2019–2022 он гэх мэт) харагдана.
- **†** — үеийн дундаас түүх эхэлсэн тул өөрийн эхний хаалтаас тооцсон (бүтэн үе биш). Дундаж, өссөн/унасан тоонд орохгүй.
- **арилжаагүй** — үеийн турш нэг ч арилжаагүй (хаалт өмнөхөөрөө, дундажид 0%).
- **Хамрагдсан компани** мөр — тухайн баганын дунджид орсон компанийн тоо. 20-оос цөөн бол дундаж саарал.

## Өдрийн хязгаар ±15% ба засвар
МХБ-ийн өдрийн ханшийн хэлбэлзлийн хязгаар ±15%. Дараалсан хоёр арилжааны өдрийн хаалт үүнээс их (+1 ₮ алхмын зөрүү)
өөрчлөгдсөн бол хувьцаа хуваалт / нэгтгэл эсвэл өгөгдлийн алдаа гэж үзэж Excel-ийн "15%-иас их өөрчлөлт" хуудсанд
жагсааж, чартад тикерийн хажууд ⚠ тавина. Шалгаад хуваалт бол `data/adjustments.csv` файлд нэмнэ:

```
symbol,date,factor,note
MSE,2024-05-02,0.1,1:10 хуваалт
```
Тэр өдрөөс өмнөх ханш × factor болж 4 чартад засагдана. Excel дэх тоо түүхий хэвээр.

## Түүхийн Excel (`reports/mse_history.xlsx`)
Хамрах хүрээ · Өдрийн хаалт · Сарын хаалт · Бүх өгөгдөл · 15%-иас их өөрчлөлт · Багцын арилжаа · Индекс · Ногдол ашиг.
Анхны backfill-ийн дараа үүсч, 28 хоног тутам шинэчлэгдэнэ (гараар: Run workflow → `excel`). Репод **хадгалахгүй** (.gitignore) —
шинэчлэгдэх бүрт таны хувийн Telegram чат руу илгээгдэнэ.

## Индекс (ТОП-20, MSE A, MSE B)
`index_mse.py update` өдөр бүр https://mse.mn/mse-index хуудасны өгөгдлийн хүсэлтээр (`top20ChartData`/`top20ChartList`,
`mseAChartData`, `mseBChartData`) бүх түүхийг татаж `data/history/TOP20.csv`, `MSEA.csv`, `MSEB.csv`-д хадгална.
ТОП-20 бүтэлгүйтвэл members.mse.mn-ээс тухайн өдрийн утгыг авна. Хариу `data/history/_probe/index_*.txt`-д хадгалагдана.
mse.mn сайтаа шинэчилбэл хүсэлтийн ID (`next-action`) солигдож болно — код шинэ ID-г хуудаснаас хайна; олдохгүй бол
`MSE_NEXT_ACTION` орчны хувьсагчаар өгнө.
Чартад анхдагчаар зөвхөн ТОП-20 мөр гарна. 3-ууланг нь харуулах бол workflow-ийн `env`-д `INDEX_ROWS: TOP20,MSEA,MSEB` нэмнэ.

## Ногдол ашиг ба нийт өгөөж (сонголттой)
`data/dividends.csv` файл үүсгэвэл (эх сурвалжийг өөрөө баталгаажуулж бичнэ):
```
symbol,ex_date,amount,note
APU,2026-05-15,20,2025 оны ногдол ашиг
```
Тэгвэл workflow "нийт өгөөж (ханш + ногдол ашиг)" хувилбарын чартыг `reports/total/`-д гаргаж **хувийн чат руу** илгээнэ
(суваг руу илгээхгүй). Ногдол ашгийг тухайн үеийн эцсийн ханш дээр нэмж тооцно (дахин хөрөнгө оруулалтгүй). Хуваалтын засвартай уялдана.

## Алдааны мэдэгдэл (хувийн чат, `TELEGRAM_ADMIN_CHAT_ID`)
- 3-аас олон компанийн түүх татагдаагүй;
- open.mse.mn-ийн хуудасны бүтэц өөрчлөгдсөн (компаниудын тал ба түүнээс илүүгийн хүснэгт уншигдахгүй);
- ТОП-20 индекс татагдаагүй (next-action ID солигдсон байж болзошгүй);
- 30+ хоног шинэчлэгдээгүй ханш;
- шинээр илэрсэн, `adjustments.csv`-д бүртгэгдээгүй ±15%-ийн үсрэлт;
- workflow унасан, эсвэл кодын өөрчлөлтийн дараа тест унасан.
Нэг асуудлыг өдөр бүр давтахгүй (`data/history/alerted.json`).

## Тест
`python tests/smoke.py` — зохиомол өгөгдлөөр бүх командыг шалгана. Код push хийх бүрт `.github/workflows/test.yml` автоматаар ажиллана.
